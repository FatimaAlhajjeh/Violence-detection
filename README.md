# Violence-detection

# Overview
This project explores the use of deep-learning techniques for identifying violent activity in video data.
The task involves analyzing visual information to distinguish between the classes defined in the dataset. Because video contains information across multiple frames, temporal modeling may be important to the approach.
The project investigates computer vision methods for video classification.

# Problem Statement
Video analysis can be used to study human actions and activity patterns.
Automatically classifying video clips according to their content is a challenging computer vision task because actions can vary in appearance, duration, camera angle, and background.
This project explores deep-learning approaches to classifying video data according to the dataset's labels.
